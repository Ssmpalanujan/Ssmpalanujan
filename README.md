# Featured Projects

## 🧺 Basket — Multi-Service Mobile Application

**React Native • Expo SDK 54 • JavaScript / TypeScript**

Basket is a multi-service mobile application that brings multiple
everyday services into one platform.

### Main Features

- Grocery and daily essentials delivery
- Creative studio booking
- 24/7 mechanic and roadside assistance
- Home appliance and device repair services
- Multi-service search and category browsing
- Product ratings and reviews
- Delivery and driver tracking
- Interactive maps
- Live route simulation
- Booking workflows
- Responsive mobile UI

The application was developed and tested using **Expo Go**, enabling
rapid development and real-device testing.

It also includes an Expo Go-friendly map fallback for development and
testing without requiring a production Google Maps API key.

### What I Learned

This project strengthened my skills in:

- Mobile UI development
- React Native development
- Navigation
- Responsive layouts
- Reusable components
- Location-based services
- Booking workflows
- State management
- Mobile application architecture
