# Featured Projects

## Basket

### Multi-Service Mobile Application

<p>
  <img src="https://img.shields.io/badge/React%20Native-61DAFB?style=flat-square&logo=react&logoColor=black" />
  <img src="https://img.shields.io/badge/Expo-000020?style=flat-square&logo=expo&logoColor=white" />
  <img src="https://img.shields.io/badge/Expo%20SDK%2054-000020?style=flat-square&logo=expo&logoColor=white" />
  <img src="https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black" />
  <img src="https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white" />
</p>

Basket is a multi-service mobile application designed to bring multiple
everyday services together within a single platform. The application
combines grocery and daily essentials delivery, creative studio booking,
24/7 mechanic and roadside assistance, home appliance and device repair,
product search, ratings and reviews, booking workflows, and delivery
tracking into one user-friendly mobile experience.

The application was developed using React Native and Expo SDK 54 and
tested through Expo Go to support rapid development and real-device
testing. It also includes an Expo Go-compatible map fallback with live
route simulation, while allowing Google Maps API integration for
production environments.

This project strengthened my practical experience in mobile UI
development, navigation, responsive layouts, reusable components,
location-based services, booking workflows, state management, and
mobile application architecture.

**Technologies Used:** React Native, Expo SDK 54, Expo Go, JavaScript,
TypeScript, Maps Integration, Responsive Mobile UI, State Management

## GreenLoop

### Eco-Friendly Packaging Management and Logistics System

<p>
  <img src="https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white" />
  <img src="https://img.shields.io/badge/Java%20Swing-5382A1?style=flat-square" />
  <img src="https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white" />
  <img src="https://img.shields.io/badge/JDBC-000000?style=flat-square" />
  <img src="https://img.shields.io/badge/MVC%20Architecture-6C63FF?style=flat-square" />
</p>

GreenLoop is a desktop application developed for sustainable packaging
and logistics management. The system combines inventory management,
real-time logistics tracking, sustainability analytics, CO2 offset
calculations, and circularity metrics within a centralized application.

The user interface was designed using Java Swing with FlatLaf styling,
custom Java2D vector graphics, responsive dashboards, and interactive
analytics components. The application also integrates Windows Phone
Link SMS functionality for delivery notifications together with phone
number validation and automated messaging support.

The project provided practical experience in desktop application
development, database connectivity, software architecture, analytics,
and the implementation of sustainability-focused business features.

**Technologies Used:** Java, Java Swing, MySQL, JDBC, Clean MVC
Architecture, FlatLaf, Java2D

## Web-Based Hardware Shop Management System

## Green Basket

### Grocery E-Commerce Platform

<p>
  <img src="https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black" />
  <img src="https://img.shields.io/badge/REST%20API-02569B?style=flat-square" />
  <img src="https://img.shields.io/badge/AJAX-1572B6?style=flat-square" />
  <img src="https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white" />
</p>

Green Basket is a full-stack grocery e-commerce platform developed
with the Sri Lankan market in mind. The application provides a digital
platform for customers to browse grocery products, manage their
shopping cart, and process orders.

The project focused on developing practical e-commerce functionality
while integrating REST APIs and AJAX for application communication and
dynamic interactions. MySQL was used to support a structured relational
database architecture.

The project strengthened my understanding of full-stack development,
API integration, asynchronous web communication, database design, and
real-world e-commerce workflows.

**Technologies Used:** JavaScript, REST APIs, AJAX, MySQL, Relational
Database Design
