# Featured Projects

## Basket

### Multi-Service Mobile Application

<p>
<img src="https://img.shields.io/badge/React%20Native-61DAFB?style=flat-square&logo=react&logoColor=black" />
<img src="https://img.shields.io/badge/Expo%20SDK%2054-000020?style=flat-square&logo=expo&logoColor=white" />
<img src="https://img.shields.io/badge/Expo%20Go-000020?style=flat-square&logo=expo&logoColor=white" />
<img src="https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white" />
</p>

Basket is a multi-service mobile application built with React Native and Expo SDK 54. The platform brings multiple everyday services into a single mobile application.

The application includes grocery and daily essentials delivery, creative studio booking, 24/7 mechanic and roadside assistance, home appliance and device repair services, multi-service search and category browsing, product ratings and reviews, booking workflows, and real-time delivery and driver tracking.

The application was developed and tested using Expo Go, enabling rapid React Native development and real-device testing.

It also includes an Expo Go-compatible map fallback with live route simulation and can be configured with Google Maps API integration for production builds.

This project strengthened my practical skills in mobile UI development, navigation, reusable components, responsive layouts, location-based services, booking workflows, state management, and mobile application architecture.

**Technologies Used:**
`React Native` `Expo SDK 54` `Expo Go` `JavaScript` `TypeScript` `Maps Integration` `State Management`

## GreenLoop

### Eco-Friendly Packaging & Logistics System

<p>
<img src="https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white" />
<img src="https://img.shields.io/badge/Java%20Swing-5382A1?style=flat-square" />
<img src="https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white" />
<img src="https://img.shields.io/badge/JDBC-000000?style=flat-square" />
</p>

GreenLoop is a desktop application developed for sustainable packaging and logistics management.

The system combines inventory management, logistics tracking, sustainability analytics, CO2 offset calculations, and circularity metrics within a centralized application.

The interface was developed using Java Swing with FlatLaf styling, custom Java2D graphics, dashboards, and analytics.

The application also supports delivery notification workflows through Windows Phone Link SMS functionality.

**Technologies Used:**
`Java` `Java Swing` `MySQL` `JDBC` `MVC Architecture` `FlatLaf` `Java2D`

## Final-Year Research Project

### AI-Based Recruitment Fraud Detection System

<p>
<img src="https://img.shields.io/badge/DistilBERT-FF6F00?style=flat-square" />
<img src="https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white" />
<img src="https://img.shields.io/badge/OpenCV-5C3EE8?style=flat-square&logo=opencv&logoColor=white" />
<img src="https://img.shields.io/badge/React%20Native-61DAFB?style=flat-square&logo=react&logoColor=black" />
<img src="https://img.shields.io/badge/RabbitMQ-FF6600?style=flat-square&logo=rabbitmq&logoColor=white" />
</p>

A final-year research project focused on detecting recruitment fraud using an AI-powered multi-component ecosystem.

The system uses DistilBERT for multi-label psychological-tactic classification, OpenCV and Tesseract for OCR processing, FastAPI for backend services, RabbitMQ for asynchronous communication, and React Native for the mobile frontend.

The project combines artificial intelligence, natural language processing, OCR, microservices, messaging, and mobile application development.

**Technologies Used:**
`DistilBERT` `FastAPI` `OpenCV` `Tesseract OCR` `RabbitMQ` `React Native`
